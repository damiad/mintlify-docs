El adaptador del SDK de Fastino traduce las llamadas compatibles del cliente en
operaciones sobre un trabajo interactivo de Fastino. Instala `tinker==0.33.1`
para el flujo de trabajo documentado; el conjunto de pruebas de contrato de
Fastino cubre tanto `0.32.0` como `0.33.1`.

| Elemento | Valor compatible |
| --- | --- |
| Paquete | `tinker==0.33.1` |
| URL base | `https://api.fastino.ai/v1/training/compat/tinker` |
| Autenticación | Una clave `fast_sk_` impresa por `TINKER_CREDENTIAL_CMD` |
| Identidad del recurso | Un cliente de entrenamiento es un trabajo interactivo de Fastino con el mismo ID |

El SDK añade `/api/v1/{operation}` a la URL base. Las rutas del adaptador se
ocultan del OpenAPI y de la referencia de la API. Los usuarios no deben
construir solicitudes al adaptador.

## Entrenamiento y muestreo

| Método u operación del SDK | Asignación de Fastino | Compatibilidad |
| --- | --- | --- |
| `create_lora_training_client` | Crear un trabajo interactivo mediante el SDK | Compatible |
| `copy_weights` | Iniciar un trabajo interactivo desde un checkpoint existente | Compatible |
| `TrainingClient.get_info` | Leer el trabajo interactivo | Compatible |
| `forward` | Ejecutar una operación solo hacia delante | Compatible |
| `forward_backward` | Ejecutar una operación hacia delante y hacia atrás | Compatible |
| Operación personalizada hacia delante/hacia atrás | Ejecutar una operación compatible con pérdida personalizada | Compatible |
| `optim_step` | Aplicar una actualización del optimizador | Compatible |
| `save_state` | Guardar el estado del entrenamiento | Compatible |
| `save_weights_for_sampler` | Guardar los pesos del muestreador | Compatible |
| Cargar el estado de entrenamiento | Restaurar un checkpoint de estado | Compatible |
| Crear u obtener un cliente de muestreo | Resolver los pesos del muestreador | Compatible |
| `SamplingClient.sample` | Muestrear mediante el checkpoint seleccionado | Compatible |

Conserva sin cambios el parámetro `base_model` del método del SDK. Consulta
`ServiceClient.get_server_capabilities()` antes de seleccionar un modelo base o
depender de una operación opcional. Las capacidades son la fuente de verdad;
esta referencia no establece un catálogo fijo de modelos, pérdidas, rangos,
ventanas de contexto ni límites por llamada.

## Futures

| Método u operación del SDK | Asignación de Fastino | Compatibilidad |
| --- | --- | --- |
| Resultado/obtención de future | Obtener un resultado asíncrono | Compatible |
| Cancelación de future | Solicitar la cancelación de un future | Compatible |
| Recuperación por lotes con `retrieve_futures` | Ninguna | No compatible |

## Administración

| Método u operación del SDK | Asignación de Fastino | Compatibilidad |
| --- | --- | --- |
| Listar ejecuciones de entrenamiento con `RestClient` | Listar trabajos canónicos de Fastino | Compatible |
| Obtener una ejecución de entrenamiento con `RestClient` | Obtener un trabajo canónico de Fastino | Compatible |
| Listar u obtener checkpoints | Inspeccionar los checkpoints del trabajo interactivo | Compatible |
| Descargar o eliminar un checkpoint | Administrar un checkpoint interactivo | Compatible |
| Publicar o retirar la publicación de un checkpoint | Cambiar la publicación del checkpoint | Compatible |
| Establecer o borrar el TTL de un checkpoint | Cambiar la retención del checkpoint | Compatible |
| `RestClient.get_current_checkpoint_storage_usage` | Leer el almacenamiento actual de checkpoints | Compatible |
| `RestClient.get_billing_usage` | Leer eventos horarios de uso del SDK | Compatible |

## Infraestructura exclusiva del adaptador

El SDK gestiona las capacidades, las sesiones, el heartbeat, la telemetría, las
comprobaciones de identidad, el intercambio de tokens y la infraestructura de
uso. Intercambia la clave de Fastino que imprime `TINKER_CREDENTIAL_CMD` por una
credencial de corta duración que se usa en llamadas posteriores del SDK. Son
detalles de implementación, no solicitudes HTTP que deba crear el cliente.

## Explícitamente no compatible

- Recuperación de futures por lotes mediante `retrieve_futures`
- `save_weights_external`
- `external_weights_urls`

La autenticación solo se proporciona mediante una clave normal de Fastino
`fast_sk_` a través de `TINKER_CREDENTIAL_CMD`. Las credenciales que comienzan
por `tml-` se rechazan y los ejemplos activos no deben establecer
`TINKER_API_KEY`.

Para obtener orientación sobre el ciclo de vida y la recuperación, consulta
[Comportamiento en tiempo de ejecución y errores](/es/rl-api/runtime).
