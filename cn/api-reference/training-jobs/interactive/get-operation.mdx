`GET /v1/training/operations/{idempotency_key}`

发送最初用于原生交互式 POST 或编码器任务创建的密钥。密钥按团队隔离；未知或不可访问的调用返回 `not_found`。

`accepted` 回执只表示请求已被接纳，不表示执行成功。接纳仍在进行时，`job_id`、`future_id` 和 `future_status` 可能为 null。标识已知后，使用原 future 读取结果。停止操作没有 future；编码器创建只返回任务。

如原生请求结果不确定，请用相同请求体、路由和密钥重试。同一密钥用于不同请求会返回 422；首次调用仍在进行会返回 409。新工作应使用新密钥。此端点不保证回执保留期或过期时间。

<ParamField header="X-API-Key" type="string" required>
  Fastino API key.
</ParamField>

<ParamField path="idempotency_key" type="string" required>
  Idempotency-Key.
</ParamField>

```json
{

  "status": "accepted",
  "operation": "forward-backward",
  "job_id": "SESSION_ID:train:0",
  "future_id": "FUTURE_ID",
  "future_status": "completed"
}
```

</ResponseExample>
