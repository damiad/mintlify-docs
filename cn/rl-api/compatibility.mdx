Fastino 的 SDK 适配器将受支持的客户端调用转换为对一个交互式 Fastino 任务的操作。
请安装 `tinker==0.33.1` 以使用文档所述工作流；Fastino 的契约测试同时覆盖
`0.32.0` 和 `0.33.1`。

| 项目 | 支持的值 |
| --- | --- |
| 软件包 | `tinker==0.33.1` |
| 基础 URL | `https://api.fastino.ai/v1/training/compat/tinker` |
| 身份验证 | 由 `TINKER_CREDENTIAL_CMD` 打印的 `fast_sk_` 密钥 |
| 资源标识 | 一个训练客户端就是一个具有相同 ID 的 Fastino 交互式任务 |

SDK 会将 `/api/v1/{operation}` 添加到基础 URL。适配器路由不会出现在 OpenAPI
和 API 参考中。用户不得构造适配器请求。

## 训练和采样

| SDK 方法或操作 | Fastino 映射 | 支持情况 |
| --- | --- | --- |
| `create_lora_training_client` | 通过 SDK 创建交互式任务 | 支持 |
| `copy_weights` | 从现有检查点启动交互式任务 | 支持 |
| `TrainingClient.get_info` | 读取交互式任务 | 支持 |
| `forward` | 运行仅前向操作 | 支持 |
| `forward_backward` | 运行前向和反向操作 | 支持 |
| 自定义前向/反向操作 | 运行受支持的自定义损失操作 | 支持 |
| `optim_step` | 应用优化器更新 | 支持 |
| `save_state` | 保存训练状态 | 支持 |
| `save_weights_for_sampler` | 保存采样器权重 | 支持 |
| 加载训练状态 | 恢复状态检查点 | 支持 |
| 创建或获取采样客户端 | 解析采样器权重 | 支持 |
| `SamplingClient.sample` | 通过所选检查点采样 | 支持 |

保持 SDK 方法参数 `base_model` 不变。在选择基础模型或依赖可选操作前，请查询
`ServiceClient.get_server_capabilities()`。功能是权威来源；本参考不会规定固定的模型目录、
损失目录、秩、上下文窗口或单次调用限制。

## Future

| SDK 方法或操作 | Fastino 映射 | 支持情况 |
| --- | --- | --- |
| Future result/get | 获取一个异步结果 | 支持 |
| Future cancel | 请求取消一个 future | 支持 |
| `retrieve_futures` 批量检索 | 无 | 不支持 |

## 管理

| SDK 方法或操作 | Fastino 映射 | 支持情况 |
| --- | --- | --- |
| `RestClient` 列出训练运行 | 列出规范的 Fastino 任务 | 支持 |
| `RestClient` 获取训练运行 | 获取规范的 Fastino 任务 | 支持 |
| 列出或获取检查点 | 检查交互式任务的检查点 | 支持 |
| 下载或删除检查点 | 管理交互式检查点 | 支持 |
| 发布或取消发布检查点 | 更改检查点的发布状态 | 支持 |
| 设置或清除检查点 TTL | 更改检查点保留期限 | 支持 |
| `RestClient.get_current_checkpoint_storage_usage` | 读取当前检查点存储用量 | 支持 |
| `RestClient.get_billing_usage` | 读取每小时 SDK 用量事件 | 支持 |

## 仅适配器使用的基础机制

SDK 负责功能、会话、心跳、遥测、身份检查、令牌交换和用量相关的基础机制。
它会将 `TINKER_CREDENTIAL_CMD` 打印的 Fastino 密钥交换为后续 SDK 调用所用的短期凭据。
这些都是实现细节，不是由客户自行构造的 HTTP 请求。

## 明确不受支持

- 通过 `retrieve_futures` 批量检索 future
- `save_weights_external`
- `external_weights_urls`

身份验证只能通过 `TINKER_CREDENTIAL_CMD` 提供普通的 Fastino `fast_sk_` 密钥。
以 `tml-` 开头的凭据会被拒绝，并且有效示例不得设置 `TINKER_API_KEY`。

有关生命周期和恢复指导，请参阅
[运行时行为和错误](/cn/rl-api/runtime)。
