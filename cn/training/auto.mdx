`/v1/training/auto` 是训练 API 的私有访问自治路径。你提供训练目标和成功标准；Fastino 的智能体负责规划并运行训练生命周期。

该智能体可以协调：

- 数据集准备和验证
- 候选模型训练和评估
- 问题和审批检查点
- 针对可衡量成功标准的进度
- 交付达到已批准标准的模型

<Note>
  Training Auto 目前为私有访问，不包含在公开 OpenAPI 或 API 参考中。
</Note>

在私有契约不断演进期间，本页有意不公开端点或请求 schema。
