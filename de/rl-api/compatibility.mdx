Fastinos SDK-Adapter übersetzt unterstützte Client-Aufrufe in Operationen für
einen interaktiven Fastino-Job. Installieren Sie `tinker==0.33.1` für den
dokumentierten Workflow; Fastinos Vertragstests decken sowohl `0.32.0` als auch
`0.33.1` ab.

| Element | Unterstützter Wert |
| --- | --- |
| Paket | `tinker==0.33.1` |
| Basis-URL | `https://api.fastino.ai/v1/training/compat/tinker` |
| Authentifizierung | Ein von `TINKER_CREDENTIAL_CMD` ausgegebener `fast_sk_`-Schlüssel |
| Ressourcenidentität | Ein Trainingsclient ist ein interaktiver Fastino-Job mit derselben ID |

Das SDK ergänzt die Basis-URL um `/api/v1/{operation}`. Adapter-Routen sind in
OpenAPI und API-Referenz nicht sichtbar. Benutzer dürfen Adapter-Requests nicht
selbst konstruieren.

## Training und Sampling

| SDK-Methode oder -Operation | Fastino-Zuordnung | Unterstützung |
| --- | --- | --- |
| `create_lora_training_client` | Interaktiven Job über das SDK erstellen | Unterstützt |
| `copy_weights` | Interaktiven Job aus einem vorhandenen Checkpoint starten | Unterstützt |
| `TrainingClient.get_info` | Interaktiven Job lesen | Unterstützt |
| `forward` | Reine Forward-Operation ausführen | Unterstützt |
| `forward_backward` | Forward- und Backward-Operation ausführen | Unterstützt |
| Benutzerdefinierte Forward-/Backward-Operation | Unterstützte Custom-Loss-Operation ausführen | Unterstützt |
| `optim_step` | Optimizer-Update anwenden | Unterstützt |
| `save_state` | Trainingsstatus speichern | Unterstützt |
| `save_weights_for_sampler` | Sampler-Gewichte speichern | Unterstützt |
| Trainingsstatus laden | Checkpoint auf dem interaktiven Job laden | Unterstützt |
| Sampling-Client erstellen oder abrufen | Ausgewählten Checkpoint auflösen | Unterstützt |
| `SamplingClient.sample` | Aus Checkpoint sampeln | Unterstützt |

Behalten Sie den SDK-Methodenparameter `base_model` unverändert bei. Fragen Sie
`ServiceClient.get_server_capabilities()` ab, bevor Sie ein Basismodell
auswählen oder sich auf eine optionale Operation verlassen. Die Fähigkeiten
sind die verbindliche Quelle; diese Referenz legt keinen festen Modellkatalog,
Loss-Katalog, Rang, kein Kontextfenster und kein Limit pro Aufruf fest.

## Futures

| SDK-Methode oder -Operation | Fastino-Zuordnung | Unterstützung |
| --- | --- | --- |
| Future result/get | Ein asynchrones Ergebnis abrufen | Unterstützt |
| Future cancel | Abbruch eines Future anfordern | Unterstützt |
| Batch-Abruf mit `retrieve_futures` | Keine | Nicht unterstützt |

## Verwaltung

| SDK-Methode oder -Operation | Fastino-Zuordnung | Unterstützung |
| --- | --- | --- |
| Trainingsläufe mit `RestClient` auflisten | Kanonische Fastino-Jobs auflisten | Unterstützt |
| Trainingslauf mit `RestClient` abrufen | Kanonischen Fastino-Job abrufen | Unterstützt |
| Checkpoints auflisten oder abrufen | Checkpoints interaktiver Jobs prüfen | Unterstützt |
| Checkpoint herunterladen oder löschen | Interaktiven Checkpoint verwalten | Unterstützt |
| Checkpoint veröffentlichen oder Veröffentlichung aufheben | Checkpoint-Veröffentlichung ändern | Unterstützt |
| Checkpoint-TTL festlegen oder löschen | Checkpoint-Aufbewahrung ändern | Unterstützt |
| `RestClient.get_current_checkpoint_storage_usage` | Aktuelle Checkpoint-Speichernutzung lesen | Unterstützt |
| `RestClient.get_billing_usage` | Stündliche SDK-Nutzungsereignisse lesen | Unterstützt |

## Reine Adapter-Infrastruktur

Das SDK verwaltet Fähigkeiten, Sitzungen, Heartbeat, Telemetrie,
Identitätsprüfungen, Tokenaustausch und Nutzungsinfrastruktur. Es tauscht den
von `TINKER_CREDENTIAL_CMD` ausgegebenen Fastino-Schlüssel gegen kurzlebige
Anmeldedaten aus, die für spätere SDK-Aufrufe verwendet werden. Dabei handelt
es sich um Implementierungsdetails und nicht um kundenseitig erstellte
HTTP-Requests.

## Ausdrücklich nicht unterstützt

- Batch-Abruf von Futures über `retrieve_futures`
- `save_weights_external`
- `external_weights_urls`

Die Authentifizierung erfolgt ausschließlich über einen normalen Fastino-
`fast_sk_`-Schlüssel durch `TINKER_CREDENTIAL_CMD`. Anmeldedaten, die mit
`tml-` beginnen, werden abgelehnt, und aktive Beispiele dürfen
`TINKER_API_KEY` nicht setzen.

Hinweise zu Lebenszyklus und Wiederherstellung finden Sie unter
[Laufzeitverhalten und Fehler](/de/rl-api/runtime).
