Use these contracts for field-level details. Start with the lifecycle guides when building an end-to-end training workflow.

This reference publishes the customer-facing `/v1/training/jobs` contract.
The SDK adapter under `/v1/training/compat/tinker` is intentionally hidden from
OpenAPI, and Training Auto remains private access.
